Part1

Two Key Numbers

Two numbers describe the nucleus of every atom: the atomic number counts protons, and the mass number counts protons plus neutrons.

Atomic Number

Atoms are made of three smaller particles: protons, neutrons and electrons. The number of each particle determines what element an atom is, how heavy it is and how it will behave. The most important of these is the number of protons.

  • Atomic Number – equal to the number of protons found in the nucleus of an atom
    • Atomic Number = Number of Protons
    • Each element has its own unique atomic number (change the number of protons and you have a different element)
    • Elements on the periodic table are listed in order of increasing atomic number.
    • Also represents the positive charge of the nucleus of the atom
    • Sometimes the atomic number is given the symbol “Z”
      • Ex: Z = 6 translates to atomic number = 6 (Carbon)
    • In a neutral atom, the atomic number is also equal to the number of electrons
    • Atomic Number = Number of Electrons (neutral atom)
The element Carbon (C) has an atomic number of 6. This means that every atom of carbon contains 6 protons. Its nucleus also has a charge of +6 due to those 6 protons. If the atom is neutral, it also contains 6 electrons.

Mass Number

Nearly all of an atom’s mass is found in its nucleus. Protons and neutrons each have a mass of about 1 u, while electrons are roughly 1,800 times lighter.

  • Mass Number – Total number of protons and neutrons in the nucleus of an atom.
    • Since the mass of a single proton/neutron is about 1 u, we can treat the mass number as the total mass of the protons and neutrons in an atom.
    • Mass Number = Number of Protons + Number of Neutrons
    • The mass number is always a whole number, because it counts particles.
      • It is not the same as the atomic mass on the periodic table (see Part 2).
    • To calculate the number of neutrons in an atom, we can take the mass number and subtract the atomic number (number of protons) from it.
    • Number of Neutrons = Mass Number − Atomic Number
This is the isotope symbol for an atom of Nitrogen (N). Since it has an atomic number of 7, that means it has 7 protons. If the atom is neutral it also has 7 electrons. To find the number of neutrons we take the mass number − atomic number = 14 − 7 = 7. Therefore, it also has 7 neutrons.
Protons = 7 (atomic number)Electrons = 7 (atomic number)Neutrons = 14 − 7 = 7 (mass number − atomic number)
Part2

Atomic Mass on the Periodic Table

The periodic table doesn’t list mass numbers. It lists average atomic masses, which you can round.

Atomic Mass

  • (Average) Atomic Mass – the weighted average of all naturally occurring isotopes of an element measured in unified mass units (u).
    • Unit – unified atomic mass units (u)
    • Measuring device – mass spectrometer
    • Not all atoms of a given element possess the same mass.
      • They must have the same number of protons.
      • They can differ in their number of neutrons.
    • The masses given on the periodic table represent (average) atomic masses.
      • These values include the masses of electrons in the atom.
      • They are weighted averages of all the naturally occurring isotopes.
    • If we are not provided a specific mass number to work with, we can round the average atomic mass on the periodic table to the nearest whole number to get an approximate mass of an atom of that element.
The average atomic mass of Neon (Ne) is 20.18 u. This is calculated by finding the weighted average of all the naturally occurring isotopes of Neon. For the purposes of most calculations, we can round this to the nearest whole number, 20, and treat it as the mass number for the average atom of Neon. How to calculate average atomic mass →

Isotope Symbols and Hyphen Notation

Chemists write the mass number and atomic number next to the element symbol.

Isotope Symbols

An element’s symbol tells us which element an atom belongs to, but not how many neutrons it contains or what its mass is. Chemists use a notation that places this information around the element’s symbol.

  • Isotope Symbols – notation used to identify an atom’s mass number and sometimes atomic number.
This atom of Fluorine (F) has 9 protons, equal to its atomic number. It is neutral, so it also has 9 electrons. It has 10 neutrons, found by subtracting mass number − atomic number. Note that the atomic number does not need to be given: because the element is fluorine, its atomic number must be 9.
Protons = 9 (atomic number)Electrons = 9 (atomic number)Neutrons = 19 − 9 = 10 (mass number − atomic number)

Hyphen Notation

Sometimes, an atom can be described using its element’s name or symbol followed by a hyphen and its mass number.

Element Name →Magnesium‑24Element Symbol →Mg‑24↑ Mass Number
Protons = 12 (atomic number)Electrons = 12 (atomic number)Neutrons = 24 − 12 = 12 (mass number − atomic number)
When using hyphen notation, the number provided represents the mass number. The atomic number is determined using the periodic table and name of the element. In this case, Magnesium (Mg) is atomic number 12. Therefore it has 12 protons and 12 electrons. The number of neutrons is 12 as well since the mass number − atomic number = 24 − 12 = 12.
