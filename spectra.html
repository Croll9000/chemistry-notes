Every Element’s Own Light

When excited electrons fall back, each element gives off its own set of colors.

Emission Spectra

In 1868, astronomers studying light from the sun observed a pattern of colors that did not match any element known on Earth. The element responsible was named helium, after the Greek word for the sun, and it was not found on Earth until 1895. Scientists can identify the elements in distant stars by examining the light they give off.

Each element has its own unique energy levels and therefore possible electron transitions. This means that each element can release a unique collection of light. We call this collection of light released when excited electrons return to the ground state, an emission spectrum.

  • Emission Spectrum – pattern of light emitted by atoms when electrons transition from excited states to ground states.
  • Each line comes from one specific drop between two energy levels.
    • A bigger drop gives off a photon with more energy (shorter wavelength).
    • A smaller drop gives off a photon with less energy (longer wavelength).
    • The energy levels are fixed, so only certain colors appear, not a full rainbow.
These colored lines are a visual representation of an emission spectrum. Each line represents a different wavelength/energy/color photon that is released when an electron returns to the ground state.
Note how each element’s emission spectrum is different. They are unique to each element and can be used to identify elements.

When electricity passes through a gas, each element glows with its own color.

These are also called bright-line spectra. The wavelength scale is in nanometers (nm); 1 nm = 1 × 10−9 m. Line wavelengths are from the NIST Atomic Spectra Database.

Mixtures and Emission Spectra

Since emission spectra are unique to each element, they can be used to identify elements. We can also use them to determine which elements are present in a mixture.

  • In order to say an element is in a mixture, ALL spectral lines from that element must be present in the mixture.
This mixture contains both element A and element C. All spectral lines from both elements can be found in the mixture. Although some lines from element B are in the mixture, not all of them are. Therefore, we cannot say B is present in the mixture.
