Accuracy, Precision & Percent Error

Accuracy describes how close a measurement is to the accepted value. Precision describes how close measurements are to each other. Percent error measures accuracy.

Part1

Accuracy vs. Precision

From 1889 to 2019, the kilogram was defined by a metal cylinder kept near Paris, and its official copies drifted by about 50 micrograms over a century. Scientists judge every measurement by how close it is to the true value (accuracy) and how consistent repeated measurements are (precision), and that drift was a failure of accuracy. In this section, we will distinguish accuracy from precision.

Accuracy and Precision

No measurement is perfect, so scientists must be able to judge the quality of their data. A company that makes medication, for example, must produce pills that contain the correct dose and must do so the same way every time. These two ideas, being correct and being consistent, are described by the terms accuracy and precision.

  • Accepted Value – the true or actual value of a quantity (usually from a reference table or a trusted source).
  • Measured Value – the value measured or calculated by the student during the experiment.
  • Accuracy – how close a measurement comes to the accepted (true) value.
    • Accuracy is measured by percent error.
  • Precision – how close repeated measurements are to one another.
    • An instrument with smaller increments is more precise because it allows more digits to be recorded.
    Example
    A balance that reads 2.153 g is more precise than one that reads 2.2 g.
    • These meaningful digits are called significant figures (next page).

Think of a dartboard. The bull’s-eye is the accepted value, and each dart is one measurement.

Accuracy and Precision in Data

A dart player whose darts all land in a tight cluster far from the bullseye is precise but not accurate. In the laboratory, the same ideas are judged from data: how close the average of several trials is to the accepted value, and how close the trials are to one another.

Four students each measured the density of the same aluminum sample three times. The accepted value is 2.70 g/cm³.

A set of measurements can be very precise and still be wrong. Student B probably had a systematic error, a problem that pushes every measurement the same way (like a balance that reads too high or a mistake in the procedure). Small, random differences between trials (like Student C’s) are called random error; taking more trials and averaging helps with random error.

Percent Error

A measured density of 2.80 g/cm³ for aluminum, whose accepted density is 2.70 g/cm³, is off by 0.10 g/cm³, an error of 3.7%. Dividing the error by the accepted value shows how large the error is compared with the quantity being measured, so the accuracy of very different measurements can be compared. In this section, we will calculate percent error.

Percent Error

Once an experiment is complete, scientists compare their results to accepted values to judge how successful it was. Knowing that a result is incorrect is not enough. It is more useful to know how far off it is compared to the size of the value being measured.

  • Percent Error – how far a measured value differs from the accepted value, as a percent of the accepted value.
    • Unit – percent (%)
    • A smaller percent error means a more accurate measurement.
Percent Error =Measured Value − Accepted ValueAccepted Value× 100

The percent error formula is not on the Reference Table, so memorize it. If your answer comes out negative, the measured value was lower than the accepted value; the size of the percent error is what tells you how accurate the measurement was.

Example
The accepted value for the percent by mass of water in a hydrate is 36.0%. In a laboratory activity, a student determined the percent by mass of water in the hydrate to be 37.8%. What is the percent error for the student’s measured value?
% Error =37.8 − 36.036.0× 100 = 5.0%
Example
A student determined the boiling point of a substance to be 71.8 °C. The accepted value is 70.2 °C.
% Error =71.8 − 70.270.2× 100 = 2.28%
