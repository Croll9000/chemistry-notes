Accuracy, Precision & Percent Error

Accuracy describes how close a measurement is to the accepted value. Precision describes how close measurements are to each other. Percent error measures accuracy.

Accuracy vs. Precision

Accuracy and precision.

Accuracy and Precision

No measurement is perfect, so scientists must be able to judge the quality of their data. A company that makes medication, for example, must produce pills that contain the correct dose and must do so the same way every time. These two ideas, being correct and being consistent, are described by the terms accuracy and precision.

  • Accepted Value – the true or actual value of a quantity (usually from a reference table or a trusted source).
  • Measured Value – the value measured or calculated by the student during the experiment.
  • Accuracy – how close a measurement comes to the accepted (true) value.
    • Accuracy is measured by percent error.
  • Precision – how close repeated measurements are to one another.
    • An instrument with smaller increments is more precise because it allows more digits to be recorded.
    • Ex: a balance that reads 2.153 g is more precise than one that reads 2.2 g.
    • These meaningful digits are called significant figures (next page).

Think of a dartboard. The bull’s-eye is the accepted value, and each dart is one measurement.

Percent Error

Percent error measures how far a measurement is from the accepted value.

Percent Error

Once an experiment is complete, scientists compare their results to accepted values to judge how successful it was. Knowing that a result is incorrect is not enough. It is more useful to know how far off it is compared to the size of the value being measured.

  • Percent Error – how far a measured value differs from the accepted value, as a percent of the accepted value.
    • Unit – percent (%)
    • A smaller percent error means a more accurate measurement.
Percent Error =Measured Value − Accepted ValueAccepted Value× 100

The percent error formula is not on the Reference Table, so memorize it. If your answer comes out negative, the measured value was lower than the accepted value; the size of the percent error is what tells you how accurate the measurement was.

Ex: The accepted value for the percent by mass of water in a hydrate is 36.0%. In a laboratory activity, a student determined the percent by mass of water in the hydrate to be 37.8%. What is the percent error for the student’s measured value?
% Error =37.8 − 36.036.0× 100 = 5.0%
Ex: A student determined the boiling point of a substance to be 71.8 °C. The accepted value is 70.2 °C.
% Error =71.8 − 70.270.2× 100 = 2.28%
