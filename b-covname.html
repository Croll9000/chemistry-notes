Naming Binary Covalent Compounds

Prefixes tell how many atoms.

Naming Binary Covalent Compounds

Carbon monoxide is a colorless, odorless gas that is poisonous to breathe, while carbon dioxide is exhaled with every breath. Since the same two elements can combine in different ratios, the name of a covalent compound must state exactly how many atoms of each are present.

  • Covalent compounds are made of nonmetals only. Unlike ionic compounds, there are no charges to balance, so the same two elements can combine in more than one ratio (ex: CO and CO2). The name must show the number of each atom.

When naming binary covalent compounds, follow these steps:

  1. Write the name of the 1st element in the formula. Add the appropriate prefix based on the number of atoms of that element.
    • If the element is singular, there is no need to add the prefix “mono-”.
  2. Write the name of the 2nd element. Add the appropriate prefix based on the number of atoms of that element.
  3. Remove the ending of the 2nd element’s name and replace it with “-ide”.
  • When a prefix ending in “a” or “o” comes before “oxide,” the final vowel is dropped: monoxide, tetroxide, pentoxide.

Formula Writing for Covalent Compounds

Prefixes become subscripts.

Formula Writing for Covalent Compounds

When writing the formula for binary covalent compounds, follow these steps:

  1. Write the symbol for the 1st element. If the name of the element contains a prefix, add the appropriate number as a subscript to the bottom right of that symbol.
  2. Write the symbol for the 2nd element. If the name contains a prefix, add the appropriate number as a subscript.
  • Never reduce a covalent formula. N2O4 and NO2 are two different substances.

Ionic or Covalent Naming?

  • Before naming a compound, ask: does it contain a metal or a polyatomic ion?
    • Yes, ionic: no prefixes. Use Roman numerals only for metals with more than one charge. Ex: MgCl2 is magnesium chloride, not magnesium dichloride.
    • No, two nonmetals (covalent): use prefixes. Ex: SCl2 is sulfur dichloride.
  • The next page, Ionic or Covalent? Naming & Formulas, has flowcharts for both sets of rules and games that mix the two.
