Naming Binary Covalent Compounds

Naming Binary Covalent Compounds

Dentists sometimes give patients “laughing gas” to help them relax. Its chemical name is dinitrogen monoxide, N2O, and that name is very different from nitrogen dioxide, NO2, a brown, toxic gas in smog. Both compounds contain only nitrogen and oxygen, so the name of each must state exactly how many atoms of each element it contains.

Covalent compounds are made of nonmetals only. Unlike ionic compounds, there are no charges to balance, so the same two elements can combine in more than one ratio, as in CO and CO2. Thus, the name must show the number of each atom, and it does so with Greek prefixes: mono- (1), di- (2), tri- (3), tetra- (4), penta- (5) and so on.

Two small rules keep the names from sounding awkward. If there is only one atom of the first element, the prefix “mono-” is left off, so CO2 is carbon dioxide, not monocarbon dioxide. When a prefix ending in “a” or “o” comes before “oxide,” the final vowel is dropped, giving monoxide, tetroxide and pentoxide. To name a binary covalent compound:

  • Covalent compounds are made of nonmetals only.
    • Unlike ionic compounds, there are no charges to balance, so the same two elements can combine in more than one ratio (ex: CO and CO2).
    • The name must show the number of each atom.

When naming binary covalent compounds, follow these steps:

  1. Write the name of the 1st element in the formula. Add the appropriate prefix based on the number of atoms of that element.
    • If the element is singular, there is no need to add the prefix “mono-”.
  2. Write the name of the 2nd element. Add the appropriate prefix based on the number of atoms of that element.
  3. Remove the ending of the 2nd element’s name and replace it with “-ide”.
  • When a prefix ending in “a” or “o” comes before “oxide,” the final vowel is dropped: monoxide, tetroxide, pentoxide.

Formula Writing for Covalent Compounds

Formula Writing for Covalent Compounds

The Apollo spacecraft that carried astronauts to the Moon used dinitrogen tetroxide as part of its rocket fuel. The name translates directly into a formula: “di-” means 2 nitrogen atoms and “tetr-” means 4 oxygen atoms, so the formula is N2O4. Each prefix becomes a subscript.

Covalent formulas are never reduced the way ionic formulas are. An ionic formula shows a ratio of ions in a crystal, but a covalent formula shows the actual atoms in one molecule. N2O4 and NO2 are two different substances, with different properties, so reducing N2O4 to NO2 would describe the wrong compound. To write the formula of a covalent compound:

When writing the formula for binary covalent compounds, follow these steps:

  1. Write the symbol for the 1st element. If the name of the element contains a prefix, add the appropriate number as a subscript to the bottom right of that symbol.
  2. Write the symbol for the 2nd element. If the name contains a prefix, add the appropriate number as a subscript.
  • Never reduce a covalent formula. N2O4 and NO2 are two different substances.

Ionic or Covalent Naming?

MgCl2 and SCl2 look almost the same on paper, yet one is named magnesium chloride and the other sulfur dichloride. The difference is that magnesium is a metal, so MgCl2 is ionic, and the charges of its ions decide how many chloride ions there are. Sulfur is a nonmetal, so SCl2 is covalent, and its name must state the number of chlorine atoms. Before naming any compound, the first question to ask is whether it contains a metal or a polyatomic ion. If it does, it is ionic, and no prefixes are used; Roman numerals are used only for metals with more than one charge. If it does not, it is covalent, and prefixes are used.

  • Before naming a compound, ask: does it contain a metal or a polyatomic ion?
    • Yes, ionic: no prefixes. Use Roman numerals only for metals with more than one charge.
      Note
      MgCl2 is magnesium chloride, not magnesium dichloride.
    • No, two nonmetals (covalent): use prefixes.
      Example
      SCl2 is sulfur dichloride.
