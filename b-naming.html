Ionic or Covalent? Naming & Formulas

MgCl2 is magnesium chloride, but SCl2 is sulfur dichloride. Before you can name a compound or write its formula, you have to decide which set of rules to use.

Part1

Which Set of Rules?

Deciding: Ionic or Covalent

FeCl3 is named iron(III) chloride, while PCl3 is named phosphorus trichloride, even though their formulas follow the same pattern. Chemists name ionic and covalent compounds differently because the two kinds of compounds are built differently: ionic formulas are fixed by the charges of the ions, while two nonmetals can combine in several ratios. To decide which set of rules to use, we ask whether the formula or name contains a metal or a polyatomic ion. If it does, the compound is ionic and its name uses no prefixes. If it contains only nonmetals, the compound is covalent and its name uses prefixes. A compound that contains a polyatomic ion is ionic even if every element in it is a nonmetal, as in NH4Cl, and a metalloid bonded to a nonmetal is named like a covalent compound, as in silicon tetrachloride, SiCl4.

  • Ask: does the formula or name contain a metal or a polyatomic ion?
    • Yes → ionic compound (no prefixes).
      Example
      NaCl, Fe2O3, NH4NO3
    • No (two nonmetals) → covalent compound (prefixes).
      Example
      CO2, N2O4, PCl3
  • A compound that contains a polyatomic ion is ionic, even if every element in it is a nonmetal (ex: NH4Cl).
  • A metalloid bonded to a nonmetal is named like a covalent compound (ex: SiCl4 is silicon tetrachloride).
